# Compositor 简体中文版

本汉化由 AI 制作。

为 macOS 图像编辑软件 [Compositor](https://github.com/robbietilton/Compositor) 提供简体中文界面。解压后将完整应用拖到“应用程序”中替换，打开后菜单、工具和功能面板显示中文。

**原项目：[robbietilton/Compositor](https://github.com/robbietilton/Compositor)。感谢原作者 [robbietilton](https://github.com/robbietilton) 及贡献者开源 Compositor。本仓库基于官方 1.4.5 源码提供简体中文汉化，并保留原项目的 MIT 许可及版权声明。**

这是基于官方 MIT 开源代码制作的**非官方汉化版**，当前适配 **Compositor 1.4.5（40）**。

**[下载中文版（约 5.5 MB）](https://github.com/dyries/compositor-zh-hans/releases/download/v1.4.5-zh.2/Compositor-1.4.5-zh-Hans-easy.zip)** · [最新发布](https://github.com/dyries/compositor-zh-hans/releases/latest)

下载包已包含完整应用，无需另外安装原版，也无需 Python、Xcode 或编译工具。不支持 Intel Mac。

## 怎么使用

1. **退出 Compositor。**
2. 在 Finder 的“应用程序”中选中 Compositor，按 **⌘D** 复制一份，保留为原版备份。
3. 下载并解压 `Compositor-1.4.5-zh-Hans-easy.zip`，里面有 `Compositor.app`、中文说明和许可文件。
4. 将 **Compositor.app** 拖到 Finder 的**“应用程序”**，询问时选择 **“替换”**。
5. 从“应用程序”打开 Compositor，开始使用中文界面。

首次安装可直接拖入“应用程序”。替换只涉及应用内容；自己的项目文件、图片和图层名称保留原样。若 Finder 要求管理员授权，请按 macOS 正常授权提示操作。

### 首次打开被系统阻止

汉化程序使用临时签名，**未获 Apple 公证**，不具有原版开发商的 Developer ID 签名。

如果系统提示无法验证开发者，且你确认下载来源可信，请先尝试打开一次，再进入 **“系统设置 → 隐私与安全性”**，找到对应提示，点击 **“仍要打开”** 并确认。参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

如果没有该按钮或仍无法打开，请恢复备份并在 [Issues](https://github.com/dyries/compositor-zh-hans/issues) 反馈具体提示和系统版本。此包无需关闭 Gatekeeper、SIP 等系统保护。

## 怎么恢复原版

退出 Compositor，将自己备份的原版应用拖回“应用程序”，替换当前的 Compositor，即可恢复原版。

请保留自己的原版备份；本仓库不包含接收者的原版备份。

## 汉化了哪些地方

- 菜单、工具栏、工具提示、画笔及常用工具设置。
- 图层混合模式、调整和滤镜、Camera Raw 面板。
- 保存、导出、快捷键设置及中文快捷键搜索。
- 新建项目、图层和部分自动生成内容的默认名称。

目前提供 **1,298 条中文显示资源**。RGB、HSL、sRGB、Camera Raw 等标准名称，以及用户自己命名的项目、图层和字体名称保留原文。

汉化只修改显示边界，保留 `.comp` 项目格式、混合模式、调整类型及快捷键的内部存储标识。例如，界面显示“正片叠底”，项目文件仍保存原来的 `Multiply` 标识。

**本发布版已关闭应用内自动更新**，避免官方更新覆盖汉化。以后升级原版时，需要使用与新版本匹配的汉化包。

## 源码与构建

源码基线为官方提交 [`11d8d7a`](https://github.com/robbietilton/Compositor/commit/11d8d7a50992b24fd9a760a1c13b1c01b70aaf30)。原项目介绍保存在 [UPSTREAM_README.md](../UPSTREAM_README.md)。

自行编译需要 Apple 芯片 Mac、macOS 26 或更高版本、Command Line Tools 和 Python 3；用户使用发布的中文版无需这些工具。

```sh
python3 build_chinese_app.py . ./Compositor.app --build-dir ./work-build --assets-app /Applications/Compositor.app
```

输出 `.app` 路径须尚未存在。`--assets-app` 指向已安装或解压出来的对应原版，用于复制原始图标与资产。脚本使用优化编译并保留 App Sandbox、用户选择文件读写权限及 hardened runtime，采用临时签名。

更多说明见 [汉化构建说明.md](../汉化构建说明.md)。
