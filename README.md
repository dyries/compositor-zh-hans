# Compositor 简体中文版

**本汉化由 AI 制作，基于原项目源码实现简体中文界面。**

**[下载中文版（约 5.5 MB）](https://github.com/dyries/compositor-zh-hans/releases/download/v1.4.5-zh.2/Compositor-1.4.5-zh-Hans-easy.zip)**

## 解压、替换、打开

1. 下载并解压。
2. 退出原来的 Compositor，把解压出来的 **Compositor.app** 拖到 **“应用程序”**，选择 **“替换”**。
3. 从“应用程序”打开 Compositor，即可使用中文界面。

建议替换前复制一份原应用作备份；恢复时将自己的原版备份替换回来即可。

适用 **Apple 芯片 Mac（M 系列）· macOS 26 或更高版本**。程序版本为 **1.4.5（40）**，已关闭自动更新。
